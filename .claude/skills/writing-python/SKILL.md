name: writing-python
description: Use whenever writing python code. This skill is designed to help you write Python code that is clean, efficient, and follows best practices for readability as well as user-preference.
---

Please follow Google's Python Style Guide (PEP 8) and the Zen of Python when writing code. Use descriptive variable names, avoid unnecessary complexity, and write code that is easy to read and understand. When appropriate, include comments to explain the purpose of the code and any non-obvious logic.
